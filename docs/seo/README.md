# docs/seo — SEO & AI-positioning program

Established 2026-08-17. The goal: #1 in classic search and cited-source status in AI
assistants for every torró-related query (Catalan first, Spanish second).

| File | What it is |
|---|---|
| `STRATEGY.md` | The living plan: positioning, five pillars, page roadmap, season calendar, metrics. Update every run. |
| `BASELINE_YYYY-MM-DD.md` | Dated snapshots of our status + the competition. One per check run; diff against the previous. |
| `CHECK_PROTOCOL.md` | How to re-run the measurement identically (query set, competitor watch-list, cadence, operator checklist). |
| `research/` | The evidence: nine reports from the 2026-08-17 parallel research run (SERP landscapes ca/es, competitors, keyword universe, tech-SEO standard 2026, AI/GEO standard 2026, live-site status, on-repo audit, gaps & contradictions). Re-generate or amend on major re-research, otherwise leave as the dated record. |

Quick start for a future run: read `CHECK_PROTOCOL.md`, produce a new
`BASELINE_YYYY-MM-DD.md`, update `STRATEGY.md` checkboxes, implement what the diff
demands.
